Semana 3

Base de Datos II

Actividad 3 - Semana 3

En esta actividad se desarrollan los ejercicios correspondientes a la Semana 3 del curso de Base de Datos II, aplicando conceptos de diseño, creación y administración de bases de datos.

1. Implementación de la Base de Datos Grados y Títulos

Se implementa una base de datos orientada a la gestión de información relacionada con grados académicos, títulos, estudiantes, docentes, tesis y procesos de titulación.

Creación de la Base de Datos

Se crea la base de datos que permitirá almacenar y administrar la información correspondiente al sistema de Grados y Títulos.

Diseño de Tablas

Se diseñan las tablas necesarias para organizar la información y establecer las relaciones entre las diferentes entidades del sistema.

Esquemas

Se utilizan esquemas para organizar las tablas y objetos de la base de datos de acuerdo con su función.

Restricciones

Se implementan restricciones como claves primarias, claves foráneas, valores únicos y condiciones de validación para mantener la integridad de los datos.

Ejemplo de creación de un esquema

CREATE SCHEMA Academico;

CREATE SCHEMA GradosTitulos;

CREATE SCHEMA Investigacion;

2. Cadena Editorial

Se desarrolla el modelo correspondiente a una cadena editorial, identificando las entidades, atributos y relaciones necesarias para representar la información dentro de una base de datos.

Entidades

Se identifican las principales entidades que participan en el funcionamiento de la cadena editorial.

Relaciones

Se establecen las relaciones entre las entidades para representar correctamente el funcionamiento del sistema.

Base de Datos

El modelo puede ser implementado mediante tablas, claves primarias y claves foráneas.

3. Empresa de Material Informático

Se desarrolla el modelo de datos para una empresa dedicada a la comercialización de material informático, considerando las entidades y relaciones necesarias para gestionar su información.

Productos

Se considera la información relacionada con los materiales y productos informáticos comercializados por la empresa.

Clientes

Se registra la información necesaria para identificar y gestionar a los clientes de la empresa.

Relaciones

Se establecen las relaciones entre las diferentes entidades para organizar correctamente los datos.

4. Conceptos Aplicados

  • Creación de bases de datos.
  • Creación de esquemas mediante CREATE SCHEMA.
  • Diseño y creación de tablas.
  • Claves primarias (PRIMARY KEY).
  • Claves foráneas (FOREIGN KEY).
  • Restricciones de integridad.
  • Relaciones entre tablas.
  • Organización de la información mediante esquemas.

¿Qué aprendí?

Durante la Semana 3 aprendí a aplicar conceptos de diseño y administración de bases de datos. También reforcé el uso de SQL para crear bases de datos, esquemas y tablas, además de implementar restricciones que permiten mantener la integridad de la información.

Además, comprendí la importancia de establecer correctamente las relaciones entre las tablas para organizar la información y facilitar su administración dentro de una base de datos.
