📚 ACTIVIDAD 2

En esta actividad se trabajaron los contenidos correspondientes a la segunda parte de la Semana 2, relacionados con el estudio y manejo de los sistemas de bases de datos.

Se reforzaron los conocimientos adquiridos durante la instalación de Microsoft SQL Server y se revisaron conceptos importantes para continuar con el desarrollo de las actividades prácticas de Base de Datos II.

📝 ¿Qué aprendí?

Durante esta semana aprendí los pasos necesarios para instalar y configurar Microsoft SQL Server 2022, además de conocer la función del Database Engine y de SQL Server Management Studio (SSMS) para trabajar con bases de datos.

También reforcé la importancia de contar con un entorno correctamente configurado para poder crear, administrar y consultar bases de datos mediante instrucciones SQL.
